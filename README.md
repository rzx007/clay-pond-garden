# 微缩池塘花园

Vite + TypeScript + Three.js，全部使用程序化几何，无外部模型、图片或收费素材。正交相机默认俯角约 55°，支持受限 OrbitControls，无 UI、自动旋转或鼠标指针模型。

镜头操作：左键拖动旋转、右键拖动平移、滚轮缩放、双击恢复初始视角；触屏单指旋转、双指缩放和平移。俯角限制在 25–70°，水平旋转限制为左右各 90°，缩放为 0.75–2.5 倍，平移目标限制在中心 3 单位内。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

访问终端显示的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm run build
npm run preview
```

生产文件输出到 `dist/`，可部署到静态站点服务器。

## 代码

- `src/main.ts`：正交相机、暖光、柔和阴影、尺寸适配和动画循环。
- `src/terrain.ts`：真实带孔草地、碎化边缘、浅岸线、水底颜色、木桥、土路、石头。
- `src/water.ts`：透明水面 Shader 和稀疏流动波纹，关闭深度写入以保证水下鱼可见。
- `src/plants.ts`：团状树冠、实例化草叶、花点与香蒲，以及微风动画。
- `src/animals.ts`：三条完整鱼、鸭子、荷叶花朵、花瓣与扩散水纹。

设备像素比上限 1.75；遵循系统减少动态效果设置。动画时间以秒计，鱼的封闭游动路线始终限制在中央水域。
